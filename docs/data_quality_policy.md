# Energy Planner 데이터 품질 및 GRU 학습 자격 정책

## 1. 문서 목적

이 문서는 Energy Planner에 업로드된 시간별 전력 데이터의 품질을 측정하고, 건물별 신규 GRU 학습과 최신 24시간 예측이 가능한지 판단하는 정책을 정의합니다.

적용 원칙:

- CSV 기본 입력 형식 판정과 GRU 학습 자격 판정을 분리합니다.
- 모든 시간 간격은 시간대 적용 후 UTC로 환산한 실제 시각을 기준으로 계산합니다.
- 누락된 시각은 진단용 시간축에서 결측 구간으로 기록합니다.
- 원본 CSV의 값, 시각과 행을 수정하지 않습니다.
- 결측값을 0으로 대체하거나 자동 보간하지 않습니다.
- 데이터 기간만으로 학습 또는 예측 성공을 보장하지 않습니다.
- 이 문서의 학습 기간과 품질 경계는 Phase 6-5 분할 정책 전까지 잠정 기준입니다.

## 2. 판정 단계

품질 진단은 다음 순서로 수행합니다.

1. CSV 기본 입력 형식을 검사합니다.
2. 형식을 통과한 데이터로 시간별 품질 지표를 계산합니다.
3. 연속 168시간 입력창과 168시간 입력·24시간 정답 조합을 계산합니다.
4. 시간순 Train, Validation, Test 구간을 만들 수 있는지 검사합니다.
5. GRU 학습 자격과 각 예측 방식의 실행 가능 여부를 별도로 판정합니다.

### 2.1 CSV 형식 오류

다음 문제는 데이터 품질 경고가 아니라 CSV 형식 오류입니다.

- 필수 컬럼 누락
- 해석할 수 없는 timestamp
- 시간대 미지정 또는 DST 모호성 미해결
- UTC 환산 후 중복 시각
- NaN, Inf, 음수 또는 숫자가 아닌 kwh
- 누적 검침값 입력
- 실제 입력 주기가 30분, 2시간 등 1시간이 아닌 경우
- 오프셋 포함·미포함 시각 혼용
- 여러 건물 데이터 혼합

형식 오류가 있으면 품질 등급을 계산해 학습을 시도하지 않고 `CSV_FORMAT_FAIL`로 종료합니다.

정상적인 시간별 데이터에서 일부 시각 행이 존재하지 않는 것은 입력 주기 위반과 다릅니다. 전자는 결측 구간으로 기록하고, 후자는 CSV 형식 오류로 처리합니다.

## 3. 품질 지표 정의와 계산

품질 지표는 중복이 제거된 것으로 가정하지 않습니다. 중복 시각은 앞 단계의 형식 오류로 먼저 차단합니다.

### 3.1 전체 관측 기간

- `first_timestamp`: 가장 이른 유효 timestamp
- `last_timestamp`: 가장 늦은 유효 timestamp
- 전체 관측 시간: `(last_timestamp - first_timestamp) / 1시간 + 1`
- 전체 관측 기간(일): `전체 관측 시간 / 24`

관측 기간은 양 끝 시각 사이의 범위입니다. 중간 결측이 많아도 기간 자체는 길게 보일 수 있으므로 단독으로 학습 자격을 판정하지 않습니다.

### 3.2 전체 예상 시간 수와 실제 관측 시간 수

- 전체 예상 시간 수 `H_expected`: first_timestamp부터 last_timestamp까지 1시간 간격으로 존재해야 하는 시각 수
- 실제 관측 시간 수 `H_observed`: 예상 시간축 중 유한하고 0 이상인 kwh가 존재하는 고유 시각 수
- 누락 시간 수 `H_missing = H_expected - H_observed`

진단용 1시간 시간축을 만들어 존재하지 않는 시각을 확인할 수 있지만, 원본 CSV에 행을 추가하거나 값을 채우지 않습니다.

### 3.3 전력량 결측률

`결측률(%) = H_missing / H_expected × 100`

`timestamp`는 존재하지만 `kwh`가 비어 있거나 유효하지 않은 경우 Phase 6-2 계약상 형식 오류입니다. CSV가 형식 검사를 통과한 뒤의 결측률은 주로 존재하지 않는 시간 행을 의미합니다.

### 3.4 최대 연속 결측 시간

예상 시간축에서 kwh가 존재하지 않는 연속 구간별 길이를 계산하고 그 최댓값을 사용합니다.

- 결측이 없으면 0시간
- 한 시각만 없으면 1시간
- 여러 결측 구간이 있으면 시작·종료 시각과 길이를 모두 기록하고 최댓값을 요약

최대 연속 결측은 전체 결측률이 낮더라도 특정 계절이나 평가 구간을 사용할 수 없게 만드는 위험을 보여줍니다.

### 3.5 0kWh 값

- 0값 개수: 유효 관측값 중 `kwh = 0`인 시각 수
- 0값 비율: `0값 개수 / H_observed × 100`
- 최대 연속 0시간: 0kWh가 연속된 가장 긴 구간

0kWh는 정상적인 휴무나 설비 정지일 수 있으므로 자동 결측 처리하거나 삭제하지 않습니다. 다음 경우에는 `WARNING` 근거로 기록하되 원본을 유지합니다.

- 0kWh가 24시간 이상 연속
- 0값 비율이 높아 실제 운영 패턴인지 확인이 필요한 경우
- 0값 직전·직후에 비정상적으로 큰 변화가 있는 경우

0값 비율의 최종 경고 경계는 건물 유형별 근거가 부족하므로 미확정입니다.

### 3.6 비정상 전력량과 이상치 의심 구간

비정상 전력량과 통계적 이상치 의심값을 구분합니다.

| 구분 | 정의 | 처리 |
|---|---|---|
| 비정상값 | 음수, NaN, Inf, 숫자가 아닌 값 | CSV 형식 오류 |
| 단위 의심 | kW 또는 누적 검침값으로 의심되는 입력 | 사용자 확인 전 진행 중지 |
| 이상치 의심 | 유효한 0 이상 숫자지만 주변 분포와 큰 차이가 나는 값 | WARNING, 자동 제거 금지 |
| 급변 의심 | 직전 시간 대비 변화량이 주변 변화량 분포에서 크게 벗어남 | WARNING, 자동 보정 금지 |

잠정 이상치 표시 방법:

- 수준 이상치: `Q1 - 3×IQR`보다 작거나 `Q3 + 3×IQR`보다 큰 값
- kWh가 음수가 될 수 없으므로 하한은 0 미만으로 내려가지 않게 해석
- IQR이 0이면 중앙값과 MAD 기반 검사를 보조적으로 사용
- 급변 구간은 `diff_1 = kwh(t) - kwh(t-1)`의 IQR 또는 MAD를 이용해 표시

이 규칙은 검토 대상을 찾기 위한 표시이며 오류 확정이나 삭제 기준이 아닙니다. 최종 이상치 정책은 실제 Office 학습 실험 후 확정합니다.

### 3.7 연속 168시간 입력창 개수

어떤 예측 기준 시각 직전의 168개 실제 시각이 모두 1시간 간격이고 kWh가 유효하면 하나의 입력창으로 계산합니다.

`N_input168 = Σ I(해당 168시간의 시각 연속성 충족 AND 모든 kWh 유효)`

결측이 전혀 없는 `H`시간 데이터의 이론상 입력창 수는 다음과 같습니다.

`N_input168,max = H - 168 + 1 = H - 167`

행이 168개 있다는 사실만으로 유효한 창이 아닙니다. 첫 시각부터 마지막 시각까지 실제 경과시간이 167시간이고 모든 값이 유효해야 합니다.

### 3.8 연속 168시간 입력과 후속 24시간 정답 조합 개수

입력 168시간 직후의 24시간 정답까지 모두 연속이고 유효할 때 하나의 학습·평가 조합으로 계산합니다.

`N_pair192 = Σ I(입력 168시간과 뒤따르는 정답 24시간이 모두 연속·유효)`

결측이 전혀 없는 `H`시간 데이터의 이론상 최대 조합 수:

`N_pair192,max = H - (168 + 24) + 1 = H - 191`

입력 마지막 시각과 첫 정답 시각 사이도 정확히 1시간이어야 합니다. 결측을 사이에 둔 두 구간을 이어 붙이지 않습니다.

### 3.9 Train, Validation, Test 확보 가능성

최종 분할 기간은 Phase 6-5에서 확정합니다. 이번 단계에서는 다음 의존성을 필수로 둡니다.

- 분할은 시간순 `Train → Validation → Test` 순서를 유지
- 각 조합의 입력 168시간과 정답 24시간이 소속 구간의 허용 경계를 침범하지 않아야 함
- Train에서만 스케일러를 적합
- Validation은 모델 설정과 선택에 사용
- Test는 모델 선택 후 최종 평가에만 사용
- 세 구간 각각에 유효한 192시간 조합이 존재해야 함
- 결측 때문에 한 구간의 유효 조합이 0개가 되면 GRU 학습 자격 `FAIL`
- 구간별 최소 조합 수는 Phase 6-5에서 확정

### 3.10 최신 168시간 입력 완전성

최신 유효 timestamp를 `T`라고 할 때 `T-167시간`부터 `T`까지 168개 시각이 모두 존재하고 유효한지 검사합니다.

- 완전하면 최신 GRU 예측 입력 후보
- 하나라도 누락되면 최신 GRU 24시간 예측 불가
- 과거 학습 자격이 `PASS`여도 최신 168시간이 불완전하면 현재 GRU 예측은 별도 `FAIL`
- 결측을 보간하거나 더 오래된 168시간으로 대체해 “최신 예측”이라고 표시하지 않음

최종 피처 명세가 확정되면 kWh뿐 아니라 최신 창의 모든 필수 파생 피처 완전성도 확인해야 합니다.

## 4. 잠정 품질 등급

### 4.1 공통 원칙

- 전체 등급은 가장 심각한 필수 조건을 따릅니다.
- `PASS`는 GRU 학습 자격 후보를 충족했다는 뜻이지 성능을 보장한다는 뜻이 아닙니다.
- `WARNING`은 데이터 사용이 가능하지만 제한된 실험 또는 사용자 확인이 필요하다는 뜻입니다.
- `FAIL`은 정상적인 GRU 학습·평가 구조를 만들 수 없다는 뜻입니다.
- CSV 형식 오류는 이 등급과 별도의 `CSV_FORMAT_FAIL`입니다.

### 4.2 PASS

다음을 모두 충족하면 잠정 `PASS`입니다.

- CSV 기본 입력 형식 통과
- 전체 관측 기간 180일 이상
- 결측률 5% 이하
- 최대 연속 결측 24시간 이하
- 유효한 168시간 입력·24시간 정답 조합이 존재
- 잠정 분할에서 Train, Validation, Test 모두 유효 조합 확보 가능
- 비정상값 또는 단위 의미 미해결 없음

180일, 결측률 5%, 연속 결측 24시간은 기존 BDG2 품질 분석 기준과 신규 학습의 독립 검증 필요성을 함께 고려한 잠정 기준입니다. Phase 6-5와 Office 학습 실험 후 조정할 수 있습니다.

### 4.3 WARNING

다음 중 하나 이상에 해당하지만 세 구간의 유효 조합을 확보할 수 있으면 `WARNING`입니다.

- 관측 기간 90일 이상 180일 미만
- 결측률 5% 초과
- 최대 연속 결측 24시간 초과
- 24시간 이상 연속된 0kWh
- 누적 검침값, 단위 또는 이상치 의심 패턴에 사용자 확인 필요
- 특정 계절·요일 구간의 표본이 매우 적음
- 유효 조합이 일부 기간에 집중되어 대표성이 낮음

결측률이 높거나 긴 결측 구간이 있더라도 충분한 연속 구간이 별도로 존재할 수 있으므로, 결측률이나 최대 결측 하나만으로 자동 `FAIL` 처리하지 않습니다. 다만 학습 결과에는 제한 데이터임을 표시합니다.

### 4.4 FAIL

다음 중 하나라도 해당하면 GRU 신규 학습 자격 `FAIL`입니다.

- 전체 관측 기간 90일 미만
- 유효한 168시간 입력창이 0개
- 유효한 168시간 입력·24시간 정답 조합이 0개
- 시간순 Train, Validation, Test 중 하나라도 유효 조합을 확보할 수 없음
- 결측으로 데이터가 심하게 분절되어 독립 학습·검증·평가가 불가능
- 전력 단위 또는 누적 검침 여부가 해결되지 않음
- CSV 형식 오류를 사용자가 수정하지 않음

`FAIL` 데이터에 임의 보간이나 행 삭제를 적용해 자동으로 `PASS`로 바꾸지 않습니다.

## 5. 최소 학습 기간 비교

아래 표의 조합 수는 결측이 전혀 없는 완전한 시간별 데이터에 대한 이론상 최대치입니다.

| 관측 기간 | 전체 시간 H | 최대 168시간 입력창 | 최대 168+24 조합 | 잠정 정책 | 해석 |
|---:|---:|---:|---:|---|---|
| 90일 | 2,160 | 1,993 | 1,969 | 최소 후보, `WARNING` | 세 구간 분할은 이론상 가능하지만 계절성과 독립 평가 표본이 부족할 위험이 큼 |
| 180일 | 4,320 | 4,153 | 4,129 | 권장 후보, `PASS` 가능 | 품질 기준과 분할 조건을 충족하면 기본 학습 후보 |
| 365일 | 8,760 | 8,593 | 8,569 | 장기 후보, `PASS` 가능 | 계절 범위와 반복 패턴 평가에 유리하지만 품질·연속성 검사는 동일하게 필요 |

실제 조합 수는 결측 시각 하나가 주변의 여러 168시간·192시간 창을 무효화하므로 단순히 유효 시간 수에서 결측 수를 빼서 계산할 수 없습니다.

### 5.1 90일

- 절대 최소 후보입니다.
- 완전 데이터라면 이론상 1,969개 조합을 만들 수 있습니다.
- Train, Validation, Test에 각각 최소 192시간 이상의 연속 구간이 필요합니다.
- 분할 후 구간별 조합 수와 대표성이 부족할 수 있으므로 기본 등급은 `WARNING`입니다.
- Phase 6-5에서 정한 최소 구간별 조합 수를 충족하지 못하면 `FAIL`입니다.

### 5.2 180일

- MVP의 잠정 권장 최소 기간입니다.
- 완전 데이터라면 이론상 4,129개 조합을 만들 수 있습니다.
- 결측률, 최대 연속 결측과 분할별 조합 수를 함께 충족하면 `PASS` 후보입니다.
- 180일이라는 기간만 충족하고 데이터가 분절되어 있으면 `PASS`가 아닙니다.

### 5.3 365일

- 계절 차이와 반복 운영 패턴을 포함할 가능성이 가장 높습니다.
- 완전 데이터라면 이론상 8,569개 조합을 만들 수 있습니다.
- 기간이 길어도 최근 데이터 결측, 특정 분할의 공백 또는 단위 오류가 있으면 학습·예측이 불가능할 수 있습니다.
- 365일 이상을 필수로 강제할지는 Office 실험 후 결정합니다.

## 6. 학습 가능 여부와 예측 가능 여부

각 상태는 독립적으로 판정합니다.

| 상태 | 충족 조건 | 실패 시 의미 |
|---|---|---|
| CSV 기본 입력 형식 통과 | Phase 6-2 형식, 단위, 시각 규칙 통과 | 품질·학습 검사를 시작하지 않음 |
| GRU 신규 학습 가능 | 품질 등급 `PASS` 또는 승인된 제한 실험 `WARNING`, 세 시간순 구간에 필요한 조합 확보 | 신규 GRU 학습 금지 |
| Last-24h 예측 가능 | 예측 기준 시점 직전 24시간이 실제 1시간 간격으로 모두 유효 | 직전 하루 반복 예측 불가 |
| Last-168h 예측 가능 | 향후 24개 예측 시각 각각에 대응하는 168시간 전 실제값 24개가 모두 유효 | 전주 동일 시간 반복 예측 불가 |
| 학습된 GRU 최신 예측 가능 | 승인된 모델·스케일러·피처 명세 존재, 최신 168시간과 모든 필수 피처 완전 | 학습 이력이 있어도 현재 예측 불가 |

GRU 학습이 불가능해도 Last-24h 또는 Last-168h는 필요한 최근 구간이 완전하면 실행 가능할 수 있습니다. 반대로 과거 학습 데이터가 충분해도 최신 168시간에 결측이 있으면 최신 GRU 예측은 실행하지 않습니다.

## 7. BDG2 Office 후보 근거 검토

기존 BDG2 품질 분석표의 `건물별 품질` 시트를 재사용했습니다. 원본 전력 CSV는 다시 분석하지 않았습니다.

| 건물 | 예상 시간 | 유효 시간 | 결측 시간 | 가용률 | 최대 연속 결측 | 관측 기간 | 0값 | 기존 판정 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| `Lamb_office_Maggie` | 17,544 | 17,240 | 304 | 98.27% | 22시간 | 730.92일 | 0 | 통과 |
| `Lamb_office_Callie` | 17,544 | 17,499 | 45 | 99.74% | 22시간 | 730.96일 | 0 | 통과 |
| `Hog_office_Leon` | 17,544 | 17,543 | 1 | 99.99% | 1시간 | 730.96일 | 0 | 통과 |

세 건물은 모두 다음 잠정 `PASS` 지표를 충족합니다.

- 관측 기간 180일 이상
- 결측률 5% 이하
- 최대 연속 결측 24시간 이하
- 음수값 0개
- 기존 메타데이터 매칭 완료

다만 기존 표만으로 다음 항목은 확인할 수 없습니다.

| 항목 | 상태 |
|---|---|
| 정확한 연속 168시간 입력창 개수 | 추가 측정 필요 |
| 정확한 168시간 입력·24시간 정답 조합 개수 | 추가 측정 필요 |
| Train, Validation, Test별 유효 조합 수 | 추가 측정 필요 |
| 최신 168시간 입력 완전성 | 추가 측정 필요 |
| 이상치 의심 구간과 급변 구간 | 추가 측정 필요 |
| 결측 구간의 계절·요일 편중 | 추가 측정 필요 |

결측이 없는 17,544시간 데이터의 이론상 최대 168+24 조합은 17,353개입니다. 각 후보의 실제 조합 수는 결측의 정확한 위치에 따라 달라지므로 기존 유효 시간 수만으로 계산하지 않습니다.

### 7.1 후보별 잠정 해석

- `Lamb_office_Maggie`: 결측 304시간이지만 최대 연속 결측은 22시간입니다. 전역 품질 지표는 잠정 `PASS`이나 결측 위치가 많은 입력창을 무효화할 수 있어 연속 조합 측정이 중요합니다.
- `Lamb_office_Callie`: 결측 45시간과 최대 연속 결측 22시간으로 잠정 `PASS`입니다. Maggie보다 가용률은 높지만 결측 위치에 따른 조합 손실은 별도 확인해야 합니다.
- `Hog_office_Leon`: 결측 1시간과 최대 연속 결측 1시간으로 세 후보 중 연속 표본 확보 가능성이 가장 높습니다. 정확한 조합 수와 최신 창은 여전히 추가 측정이 필요합니다.

따라서 기존 품질표는 Office 후보의 사전 선별 근거로 충분하지만 GRU 학습 자격의 최종 근거로는 부족합니다. Phase 7 실행 전에 연속 창과 분할별 조합 수를 읽기 전용으로 측정해야 합니다.

## 8. 사용자에게 표시할 판정 예

### PASS

“데이터 품질과 연속 학습 표본이 잠정 기준을 충족했습니다. 시간순 분할 정책이 확정되면 GRU 학습을 진행할 수 있습니다.”

### WARNING

“GRU 학습에 사용할 수 있는 연속 구간이 있지만 데이터 기간 또는 결측 위험이 있습니다. 제한 사항을 확인한 후 실험 학습 여부를 결정해 주세요.”

### FAIL

“연속 168시간 입력과 24시간 정답을 포함한 독립 학습·검증·평가 구간을 확보할 수 없어 GRU를 학습할 수 없습니다.”

### 최신 예측 불가

“학습된 모델은 존재하지만 최신 168시간 입력에 누락된 시각이 있어 현재 기준 24시간 예측을 생성할 수 없습니다.”

## 9. 현재 미확정 정책

다음 항목은 후속 단계에서 확정합니다.

- Train, Validation, Test의 정확한 기간 또는 비율
- 각 분할에 필요한 최소 168+24 조합 수
- 분할 경계에서 과거 168시간 문맥을 공유할지 여부와 허용 범위
- 결측률 5%와 최대 연속 결측 24시간 기준의 최종 채택 여부
- `WARNING` 데이터의 GRU 실험 학습 허용 절차
- 0kWh 비율과 연속 0시간의 최종 경고 경계
- 이상치 탐지 방식과 경고 경계
- 신규 피처 생성 후 피처별 완전성 기준
- 최신 예측 기준 시점의 정의
- 365일 이상을 권장할지 필수로 할지 여부

## 10. Phase 6-4 진행 조건

Phase 6-4에서는 모델 성능 평가와 채택 기준을 설계할 수 있습니다. 다만 다음 내용을 유지해야 합니다.

- 이 문서의 `PASS`는 학습 입력 자격이며 모델 성능 합격을 의미하지 않음
- GRU와 Last-24h, Last-168h를 동일한 평가 구간에서 비교
- 모델 선택은 Validation에서 수행하고 Test는 최종 평가에만 사용
- Phase 6-5에서 시간순 분할과 구간별 최소 조합 수를 최종 확정
- Office 후보의 연속 창 수는 실행 단계에서 추가 측정

Phase 6-4 진행은 가능하지만 PM이 잠정 180일 권장 기준과 `PASS / WARNING / FAIL` 경계를 검토한 후 승인해야 합니다.

## 11. 근거와 한계

- 서비스 입력·학습 원칙: 승인된 MVP 정의서와 CSV 입력 규격
- Office 후보 지표: 기존 BDG2 건물 품질 분석표의 `건물별 품질` 시트
- 기존 분석표는 가용률, 최대 연속 결측, 관측 기간, 음수·0값을 제공하지만 연속 학습창과 시간순 분할별 조합 수는 제공하지 않음
- 이번 단계에서는 원본 BDG2 전력 데이터 재분석, 모델 학습과 데이터 전처리를 수행하지 않음

## 12. Phase 7-4 품질 고도화 확정 사항

실제 Office 사전 점검에서 장기간 동일한 양수 값이 반복되고 Train 구간이 0분산인 사례가 확인되어 다음 규칙을 추가합니다.

- 동일한 kWh가 168시간 이상 연속되면 `WARNING_LONG_CONSTANT_RUN_168H`를 기록합니다.
- 하나의 정확한 값이 전체 유효 관측의 50% 이상이면 `WARNING_DOMINANT_VALUE_OVER_50_PERCENT`를 기록합니다.
- 위 두 조건을 충족하면서 이후 다른 값이 존재하면 `WARNING_SUSPECTED_METER_STATE_TRANSITION`을 기록합니다.
- Train kWh가 모두 동일하면 `FAIL_TRAIN_ZERO_VARIANCE`로 신규 GRU 학습을 차단합니다. 임의 잡음 추가나 scale 강제 대체로 우회하지 않습니다.
- Train 대비 Validation 또는 Test 평균 차이가 Train 표준편차의 1배 이상이면 분포 이동 WARNING을 기록합니다. 이 경고만으로 값을 제거하거나 Test를 모델 선택에 사용하지 않습니다.
- 전체 품질 판정, 분할별 분포 진단, 최신 168시간 예측 자격은 별도 상태로 사용자에게 표시합니다.

이 수치는 MVP 진단용 잠정 기준입니다. 값의 의미가 확인되지 않은 장기 상수 구간은 결측으로 자동 변환하지 않습니다.
