선택한 파일

브라우저에서 선택됨 · 아직 품질 진단 전

timestamp는 1시간 구간의 시작 시각, kwh는 해당 시간의 소비 에너지량입니다. 누적 검침값이나 순간 전력(kW)은 지원하지 않습니다. 180일 이상을 권장합니다.

건물 ID는 서버가 자동 생성합니다. timestamp의 UTC 오프셋은 자동 인식하며, 오프셋이 없으면 선택한 건물 시간대를 적용합니다.
