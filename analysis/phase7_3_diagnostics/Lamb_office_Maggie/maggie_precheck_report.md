# Energy Planner — Phase 7-3 Maggie 읽기 전용 사전 점검 보고서

## 1. 판정

- 대상: `Lamb_office_Maggie`
- 메타데이터: site `Lamb`, primary/sub-primary use `Office / Office`, electricity `Yes`, timezone `Europe/London`
- 단위: BDG2 electricity hourly meter reading의 프로젝트 해석인 시간 구간별 kWh. 원본값에 단위 변환을 적용하지 않았다.
- **형식·최소 표본 정책 판정: PASS**
- **실제 학습 승인 권고: HOLD / WARNING**
- **최신 24시간 예측 자격: FAIL** — 최신 168시간 안에 1시간 결측이 있다.
- Maggie GRU 학습, 모델 선택, Test 추론은 실행하지 않았다.

정량 최소 기준은 충족하지만 180일 중 81.13%가 정확히 `0.0002kWh`이고 부하가 2017-11-28부터 갑자기 활성화된다. 이 값이 실제 대기부하인지, 결측 대체값·계량기 비활성 상태인지 확인하기 전에는 180일 전체를 정상 Train 데이터로 간주하면 안 된다.

## 2. 최신 180일과 시간대

- Maggie 마지막 유효 관측: `2017-12-31 23:00:00` 원본 로컬 라벨
- 최신 180일: `2017-07-05 00:00:00` ~ `2017-12-31 23:00:00`
- 원본 격자: 4,320시간
- 처리 규칙: BDG2의 DST 없는 연속 로컬 격자를 보존하기 위해 `Europe/London` 메타데이터를 고정 표준시 `Etc/GMT`로 변환
- 변환 후 UTC: `2017-07-05 00:00:00Z` ~ `2017-12-31 23:00:00Z`

이 규칙은 BDG2 전용이다. 실제 런던 민간시각의 IANA DST(`Europe/London`, 여름 UTC+1)를 복원하지 않는다. 향후 Maggie run에는 다음을 기록해야 한다.

```json
{
  "source_timezone_mode": "bdg2_naive_local_grid_fixed_standard",
  "source_timezone_metadata": "Europe/London",
  "feature_timezone": "Etc/GMT",
  "dst_applied": false,
  "utc_offset_hours": 0
}
```

## 3. 데이터 품질

| 항목 | 결과 |
|---|---:|
| 예상 시간 | 4,320 |
| 유효 관측 | 4,319 |
| 결측 | 1시간, 0.0231% |
| 결측 시각 | 2017-12-25 16:00 원본 로컬 라벨 |
| 최대 연속 결측 | 1시간 |
| 최소 / 평균 / 표준편차 / 최대 | 0.0002 / 0.9592 / 2.8832 / 24.1000 kWh |
| 음수 / 0값 | 0 / 0 |
| 정확히 0.0002kWh | 3,504시간, 81.13% |
| 0.0002 초과 최초 시각 | 2017-11-28 00:00 원본 로컬 라벨 |
| 완전한 168시간 창 | 4,001 |
| 완전한 168+24 조합 | 3,977 |
| 최신 168시간 완전성 | FAIL |

월별로 7~10월은 모든 관측이 0.0002kWh이고 표준편차가 0이다. 11월 평균은 0.6587kWh, 최대 16.9kWh이고, 12월 평균은 4.9367kWh, 최대 24.1kWh다. 이는 Leon보다 훨씬 큰 **상태 전환 또는 계측 의미 변경 의심**이다.

현재 품질 코드의 IQR 진단은 `IQR == 0`이면 이상치 개수를 0으로 반환한다. Maggie는 75% 분위까지 0.0002라 IQR이 0이므로 `suspicious_outlier_count=0`이지만, 이것이 24.1kWh 피크나 분포 전환이 정상임을 뜻하지 않는다. 12월 13일 12~16시에는 21.8~24.1kWh가 연속된다. 값은 삭제·보정하지 않았으며 추가 측정·의미 확인이 필요하다.

## 4. 시간순 분할과 표본 자격

| 구분 | UTC 경계 | 유효 조합 | 잠정 기준 | 결과 |
|---|---|---:|---:|---|
| Train dense | 2017-07-05 00:00 ≤ t < 2017-11-02 00:00 | 2,689 | 1,000 | PASS |
| Validation dense | 2017-11-02 00:00 ≤ target < 2017-12-02 00:00 | 697 | 168 | PASS |
| Validation 비중복 | 동일 구간, 24시간 간격 | 30 | 12 | PASS |
| Test 비중복 | 2017-12-02 00:00 ≤ target < 2018-01-01 00:00 | 23 | 12 | PASS |

Validation 제외는 0개다. Test의 고정 30개 일정 중 7개는 12월 25일 16시 결측이 168시간 입력 문맥 또는 24시간 정답에 걸려 제외된다. 남은 23개는 최소 12개 기준을 충족한다.

따라서 현행 Phase 6-5의 기계적 학습 자격은 PASS다. 그러나 Train 기간은 전부 0.0002kWh이며 실제 부하 변화는 Validation 말부터 나타난다. 이 상태에서 Train scaler의 분산은 0이 되고, Train이 학습해야 할 운영 패턴을 포함하지 않으므로 **정책 PASS와 실험 타당성은 일치하지 않는다.** 실제 학습 전 별도 운영 데이터 충분성 규칙이 필요하다.

## 6. 실제 학습 전 해결해야 할 문제

1. `0.0002kWh`가 실제 계측값인지, 센서 오프라인/결측 대체/최소값 코딩인지 BDG2 cleaning 문서와 원시 계량열로 확인한다.
2. 2017-11-28 상태 전환이 설비 운영 개시인지 계량기 교체·단위 변경인지 확인한다.
3. Phase 6-3 품질 정책에 `장기 상수 구간`, `Train 0분산`, `Train과 Validation/Test 분포 단절`을 WARNING 또는 FAIL로 추가할지 PM이 결정한다.
4. 현행 최신 180일을 그대로 유지할지, 활성 계측 기간만 사용하되 90일 미만 FAIL 정책을 적용할지 결정한다. 활성 기간만 보면 약 34일이므로 현재 학습 자격은 FAIL이 된다.
5. 최신 168시간 결측을 보간하지 않는다. 최신 예측은 새로운 완전 관측 168시간이 확보될 때까지 차단한다.
6. 승인된 시간대 manifest 필드를 구현한 뒤에만 실제 run을 생성한다.

## 7. PM 승인 요청

다음 작업으로 Maggie 학습을 바로 승인하지 않는 것을 권고한다. 먼저 **Maggie 원시값·0.0002 의미 감사와 품질 정책 보완**을 읽기 전용 작업으로 승인하고, 그 결과에 따라 Maggie 실험의 기간과 자격을 재판정해야 한다.
