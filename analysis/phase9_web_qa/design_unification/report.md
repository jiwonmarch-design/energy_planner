# Phase 9 웹페이지 디자인 통일성 개선 보고서

검증일: 2026-11-02

## 범위

- Landing Hero와 CSV 입력, 품질 판정, 모델·예측 대시보드의 Editorial Contour 디자인 통일
- 기존 Vanilla HTML/CSS/JavaScript, DOM ID, API 계약과 ML 동작 유지
- Chrome DevTools Protocol을 이용한 1440px, 390px, 320px 실제 브라우저 검증

## 수정 전 관찰

- Hero는 Paper·Navy·Cobalt 체계이나 작업영역은 녹색·세리프·큰 라운드 카드 중심으로 시각 언어가 분리됨
- CSV 입력 → 품질 판정 → 모델·예측의 전체 흐름을 한눈에 확인하기 어려움
- 예시 예측과 실제 저장 모델 결과의 구분이 작은 태그와 설명에만 의존함
- 모바일 차트 카드에 불필요한 세로 여백이 많음

## 적용 결과

- 전역 디자인 토큰을 `#F4F2EA`, `#204ED5`, `#17212C`, `#526579`, `#BAC3CC`로 정렬
- 3단계 진행 내비게이션 추가
- 제목과 지표의 서체 계층을 Hero의 산세리프 체계로 통일
- 카드, 입력창, 버튼, 드롭존의 선·모서리·상태 표현 통일
- 대시보드를 데스크톱 12열, 모바일 단일 열 구조로 정리
- 예시 데이터 태그와 안내 영역을 Cobalt 계열로 강조
- 기존 차트의 녹색 선을 CSS만으로 Cobalt에 매핑하여 `app.js` 로직 유지
- `hidden` 요소가 작성자 CSS에 의해 다시 표시되던 문제를 수정
